## 功能特点

- **整个键盘，实时显示。** 每个按键在你按下时都会亮起。可以平面、3D 或 3D 倾斜显示。
- **12 种键位布局：** 全尺寸、无数字键盘、60%、65%、75%、96%、40%、游戏、数字键盘、方向键、WASD 键区或功能键行。
- **500 种键盘外壳和 500 种配色风格。** 悬浮按键，或带外壳包围：纤薄、矮轴、木质、复古、打字机、坚固等等。将指针停在某一项上即可在真实覆盖层上预览。
- **按下动画、松开淡出和按键计数。**
- **同样提供鼠标覆盖层**，位于独立窗口中：13 个系列共 200 款逼真的 3D 鼠标，100 套配色，以及点击时点亮的颜色。可自定义外壳、宽度、滚轮、拇指托和侧键。
- **打造你自己的布局：** 在布局设计器中，按键采用真实尺寸。可在“我的键盘”中重命名、编辑和删除。
- **放在任何位置：** 拖动键盘或鼠标即可移动，拖动边缘即可调整大小。可设置不透明度，以及各自是否保持在最前。
- **输入密码时隐藏：** 一个热键即可隐藏键盘并停止读取按键。
- **热键全局有效：** Ctrl+F9 移动键盘，Ctrl+Shift+F9 移动鼠标，Ctrl+F10 隐藏键盘，Ctrl+F11 显示或隐藏鼠标。所有热键均可更改。
- **键盘上印有 72 种键盘语言**的字符，应用界面支持 **54 种语言**。
