Ցանկացած էկրանի ձայնագրիչ կամ հեռարձակման ծրագիր ձայնագրում է էկրանը հենց այնպես, ինչպես երևում է՝ [Myna Screen Recorder](https://github.com/myna-recorder/Myna-Screen-Recorder), OBS, Streamlabs կամ Windows Game Bar։ Կանաչ էկրան պետք չէ, վերնագրի գիծ չկա, ոչինչ հեռացնելու չկա։

## Հնարավորություններ

- **Ամբողջ ստեղնաշարը, իրական ժամանակում։** Յուրաքանչյուր ստեղն լուսավորվում է, երբ սեղմում եք։ Նկարեք այն հարթ, եռաչափ կամ թեք եռաչափ։
- **12 ստեղնաշարի դասավորություն․** լրիվ չափ, tenkeyless, 60%, 65%, 75%, 96%, 40%, gaming, թվային բլոկ, սլաքներ, WASD խումբ կամ ֆունկցիոնալ շարք։
- **500 ստեղնաշարի պատյան և 500 գունային ոճ։** Լողացող ստեղներ կամ դրանց շուրջ պատյան՝ բարակ, ցածրապրոֆիլ, փայտ, ռետրո, գրամեքենա, ամուր և այլն։ Մկնիկը դրա վրա պահելով՝ իրական ծածկույթի վրա կտեսնեք նախադիտում։
- **Սեղմման անիմացիա, բաց թողնելու մարում և սեղմումների հաշվիչներ։**
- **Նաև մկնիկի ծածկույթ,** առանձին պատուհանում՝ 200 իրատեսական եռաչափ մկնիկ 13 ընտանիքում, 100 գունային հավաքածու, և այն գույնը, որով լուսավորվում են ձեր սեղմումները։ Կարող եք կարգավորել մարմինը, լայնությունը, անիվը, բթամատի հենարանը և կողային կոճակները։
- **Կառուցեք ձեր սեփական դասավորությունը** Layout Designer-ում․ ստեղները ստանում են իրական չափերը։ Վերանվանեք, խմբագրեք և ջնջեք դրանք «Իմ ստեղնաշարերը» բաժնում։
- **Տեղադրեք ուր ուզում եք․** քաշեք ստեղնաշարը կամ մկնիկը՝ տեղափոխելու համար, քաշեք եզրերը՝ չափը փոխելու համար։ Կարգավորեք թափանցիկությունը և յուրաքանչյուրի համար՝ արդյոք այն միշտ վերևում մնա։
- **Թաքցրեք գաղտնաբառերի համար․** մեկ դյուրանցումով ստեղնաշարը թաքցվում է և դադարում է ստեղների ընթերցումը։
- **Դյուրանցումներ, որոնք աշխատում են ամենուր․** Ctrl+F9-ը տեղափոխում է ստեղնաշարը, Ctrl+Shift+F9-ը՝ մկնիկը, Ctrl+F10-ը թաքցնում է ստեղնաշարը, Ctrl+F11-ը ցույց է տալիս կամ թաքցնում մկնիկը։ Բոլորը կարելի է փոխել։
- **72 ստեղնաշարի լեզու** ստեղների վրա տպված, իսկ հավելվածը՝ **54 լեզվով**։

## Ներբեռնում

Վերջին տարբերակը ստացեք [ներբեռնման էջից](https://mynarecorder.com/input-visualizer/download) կամ այս էջի [Թողարկումներից](https://github.com/myna-recorder/Myna-Input-Visualizer/releases)․ **տեղադրիչը** (տեղադրվում է Program Files-ում և մեկ անգամ պահանջում է ադմինիստրատորի իրավունք) կամ **դյուրակիր** exe-ը, որն աշխատում է առանց տեղադրման։

Ֆայլը բացելիս Windows-ը կարող է ցույց տալ «Windows-ը պաշտպանել է ձեր համակարգիչը» հաղորդագրությունը։ Ընտրեք **Ավելին**, ապա՝ **Միևնույն է, գործարկել**։

**Պահանջներ․** Windows 10 (2004 կամ ավելի նոր տարբերակ) կամ Windows 11, 64-բիթանոց, և ինտերնետ կապ մեկնարկի ժամանակ։ Մուտք գործեք Myna հաշվով կամ շարունակեք առանց դրա։
