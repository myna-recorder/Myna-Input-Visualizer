โปรแกรมบันทึกหน้าจอหรือสตรีมใดก็ตามที่จับภาพหน้าจอจะบันทึกออกมาตามที่เห็นจริง ไม่ว่าจะเป็น [Myna Screen Recorder](https://github.com/myna-recorder/Myna-Screen-Recorder), OBS, Streamlabs หรือ Windows Game Bar ไม่ต้องใช้จอสีเขียว ไม่มีแถบชื่อเรื่อง ไม่ต้องตัดขอบออกแต่อย่างใด

## คุณสมบัติ

- **คีย์บอร์ดทั้งชุดแบบสด** ทุกปุ่มจะสว่างขึ้นเมื่อคุณกด แสดงแบบแบน แบบ 3D หรือแบบ 3D เอียงได้
- **เลย์เอาต์คีย์บอร์ด 12 แบบ:** ขนาดเต็ม tenkeyless, 60%, 65%, 75%, 96%, 40%, แบบเกมมิง, แป้นตัวเลข, ปุ่มลูกศร, ชุดปุ่ม WASD หรือแถวปุ่มฟังก์ชัน
- **เคสคีย์บอร์ด 500 แบบ และสีสไตล์ 500 แบบ** ทั้งปุ่มลอยหรือมีเคสล้อมรอบ เช่น แบบบาง โปรไฟล์ต่ำ ไม้ วินเทจ พิมพ์ดีด ทนทาน และอื่นๆ อีกมาก เพียงวางตัวชี้เมาส์บนรายการใดก็จะแสดงตัวอย่างบนโอเวอร์เลย์จริง
- **แอนิเมชันตอนกด การจางหายตอนปล่อย และจำนวนครั้งที่กด**
- **โอเวอร์เลย์เมาส์ด้วย** อยู่ในหน้าต่างของตัวเอง มีเมาส์ 3D สมจริง 200 รุ่นใน 13 ตระกูล ชุดสี 100 ชุด และสีที่ปุ่มจะสว่างเมื่อคุณคลิก ปรับแต่งตัวเครื่อง ความกว้าง ล้อเลื่อน ที่วางนิ้วโป้ง และปุ่มด้านข้างได้
- **สร้างเลย์เอาต์ของคุณเอง** ใน Layout Designer ปุ่มจะมีขนาดจริงของมัน เปลี่ยนชื่อ แก้ไข และลบได้ในส่วน My keyboards
- **วางได้ทุกที่:** ลากคีย์บอร์ดหรือเมาส์เพื่อย้ายตำแหน่ง ลากขอบเพื่อปรับขนาด ตั้งค่าความทึบแสง และเลือกได้ว่าจะให้แต่ละอันอยู่บนสุดหรือไม่
- **ซ่อนเมื่อพิมพ์รหัสผ่าน:** ปุ่มลัดเพียงปุ่มเดียวจะซ่อนคีย์บอร์ดและหยุดอ่านการกดปุ่ม
- **ปุ่มลัดที่ใช้ได้ทุกที่:** Ctrl+F9 ย้ายคีย์บอร์ด, Ctrl+Shift+F9 ย้ายเมาส์, Ctrl+F10 ซ่อนคีย์บอร์ด, Ctrl+F11 แสดงหรือซ่อนเมาส์ เปลี่ยนแปลงได้ทั้งหมด
- **ตัวอักษรคีย์บอร์ด 72 ภาษา** พิมพ์อยู่บนปุ่ม และแอปรองรับ **54 ภาษา**

## ดาวน์โหลด

รับเวอร์ชันล่าสุดได้จาก [หน้าดาวน์โหลด](https://mynarecorder.com/input-visualizer/download) หรือจาก [Releases](https://github.com/myna-recorder/Myna-Input-Visualizer/releases) ในหน้านี้: **ตัวติดตั้ง** (จะติดตั้งลงใน Program Files และขอสิทธิ์ผู้ดูแลระบบหนึ่งครั้ง) หรือไฟล์ exe **แบบสแตนด์อโลน** ที่รันได้โดยไม่ต้องติดตั้ง

เมื่อคุณเปิดไฟล์ Windows อาจแสดงข้อความ "Windows ป้องกันพีซีของคุณแล้ว" ให้เลือก **ข้อมูลเพิ่มเติม** แล้วจึงเลือก **เรียกใช้อยู่ดี**

**ความต้องการของระบบ:** Windows 10 (เวอร์ชัน 2004 ขึ้นไป) หรือ Windows 11 แบบ 64 บิต และการเชื่อมต่ออินเทอร์เน็ตตอนเริ่มทำงาน ลงชื่อเข้าใช้ด้วยบัญชี Myna หรือดำเนินการต่อโดยไม่ต้องใช้บัญชีก็ได้
