<h1 align="center">Myna Input Visualizer</h1>

<p align="center">
  您的按鍵與點擊，即時呈現在螢幕上。<br>
  以無邊框、真正透明的浮動覆層即時顯示您的整個鍵盤與滑鼠。適用於 Windows 10 與 11。
</p>

任何會擷取螢幕的錄影或直播工具，例如 [Myna Screen Recorder](https://github.com/myna-recorder/Myna-Screen-Recorder)、OBS、Streamlabs 或 Windows Game Bar，都會忠實錄下畫面原樣。無需綠幕，沒有標題列，也不必去背。

## 功能

- **完整鍵盤，即時呈現。** 每個按鍵在您按下時都會亮起。可以平面、3D 或 3D 傾斜顯示。
- **12 種鍵盤配列：** 全尺寸、無數字鍵盤（tenkeyless）、60%、65%、75%、96%、40%、遊戲、數字鍵盤、方向鍵、WASD 區塊或功能鍵列。
- **500 種鍵盤外殼與 500 種配色。** 可選浮動按鍵，或帶外殼的樣式：薄型、低輪廓、木質、復古、打字機、堅固型等。將游標移到某個樣式上，即可在實際覆層上預覽。
- **按下動畫、放開淡出與按鍵次數統計。**
- **獨立視窗的滑鼠覆層：** 13 個系列共 200 款逼真 3D 滑鼠、100 組配色，以及點擊時發亮的顏色。可自訂外殼、寬度、滾輪、拇指靠墊與側鍵。
- **在 Layout Designer 中自建配列：** 按鍵採用實際尺寸。在「我的鍵盤」中重新命名、編輯與刪除。
- **自由放置：** 拖曳鍵盤或滑鼠即可移動，拖曳邊緣即可調整大小。可設定透明度，以及各自是否保持在最上層。
- **輸入密碼時隱藏：** 一個快捷鍵即可隱藏鍵盤並停止讀取按鍵。
- **快捷鍵隨處可用：** Ctrl+F9 移動鍵盤，Ctrl+Shift+F9 移動滑鼠，Ctrl+F10 隱藏鍵盤，Ctrl+F11 顯示或隱藏滑鼠。所有快捷鍵皆可更改。
- **按鍵上印有 72 種鍵盤語言**，應用程式介面支援 **54 種語言**。
