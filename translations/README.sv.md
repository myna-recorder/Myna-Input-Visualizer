<p align="center">

Alla skärminspelare eller streamingprogram som spelar in skärmen spelar in den precis så som den ser ut: [Myna Screen Recorder](https://github.com/myna-recorder/Myna-Screen-Recorder), OBS, Streamlabs eller Windows Game Bar. Ingen grön skärm, ingen namnlist, inget att klippa bort.

## Funktioner

- **Hela ditt tangentbord, live.** Varje tangent lyser när du trycker på den. Rita det platt, i 3D eller i 3D med lutning.
- **12 tangentbordslayouter:** full storlek, tenkeyless, 60%, 65%, 75%, 96%, 40%, gaming, sifferblock, piltangenter, ett WASD-kluster eller funktionsraden.
- **500 tangentbordshöljen och 500 färgstilar.** Fristående tangenter eller ett hölje runt dem: smala, låg profil, trä, retro, skrivmaskin, robusta och mer. Placera pekaren över ett för att förhandsgranska det direkt på det riktiga overlayen.
- **Tryckanimation, tonande bortfall och tryckräknare.**
- **Ett musoverlay också,** i ett eget fönster: 200 realistiska 3D-möss i 13 familjer, 100 färguppsättningar, och färgen som dina klick tänds i. Anpassa kroppen, bredden, hjulet, tumstödet och sidoknapparna.
- **Bygg din egen layout** i Layout Designer: tangenterna får sina verkliga storlekar. Byt namn på, redigera och ta bort dem under Mina tangentbord.
- **Placera den var du vill:** dra tangentbordet eller musen för att flytta den, dra i kanterna för att ändra storlek. Ställ in opaciteten och om var och en ska ligga överst.
- **Dölj den för lösenord:** en snabbtangent döljer tangentbordet och slutar läsa tangenter.
- **Snabbtangenter som fungerar överallt:** Ctrl+F9 flyttar tangentbordet, Ctrl+Shift+F9 flyttar musen, Ctrl+F10 döljer tangentbordet, Ctrl+F11 visar eller döljer musen. Alla kan ändras.
- **72 tangentbordsspråk** tryckta på tangenterna, och appen på **54 språk**.

## Hämta

Hämta den senaste versionen från [nedladdningssidan](https://mynarecorder.com/input-visualizer/download) eller [Releases](https://github.com/myna-recorder/Myna-Input-Visualizer/releases) på den här sidan: **installationsprogrammet** (det installeras i Program Files och frågar efter administratörsrättigheter en gång), eller den **fristående** exe-filen som körs utan installation.

När du öppnar filen kan Windows visa "Windows skyddade din dator". Välj **Mer information** och sedan **Kör ändå**.

**Krav:** Windows 10 (version 2004 eller senare) eller Windows 11, 64-bitars, och en internetanslutning när appen startar. Logga in med ett Myna-konto eller fortsätt utan.
