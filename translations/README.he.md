כל מקליט מסך או שידור שמצלם את המסך מתעד אותו בדיוק כפי שהוא נראה: [Myna Screen Recorder](https://github.com/myna-recorder/Myna-Screen-Recorder), OBS, Streamlabs או סרגל המשחקים של Windows. בלי מסך ירוק, בלי שורת כותרת, ואין מה לחתוך החוצה.

## תכונות

- **כל המקלדת שלך, בשידור חי.** כל מקש נדלק כשאתה לוחץ עליו. אפשר להציג אותה שטוחה, בתלת-ממד, או בתלת-ממד מוטה.
- **12 פריסות מקלדת:** גודל מלא, ללא מקלדת נומרית, 60%, 65%, 75%, 96%, 40%, גיימינג, מקלדת נומרית, מקשי חצים, אשכול WASD או שורת מקשי הפונקציה.
- **500 מארזי מקלדת ו-500 סגנונות צבע.** מקשים צפים או מארז שעוטף אותם: דק, פרופיל נמוך, עץ, רטרו, מכונת כתיבה, עמיד ועוד. הניחו את הסמן על אחד מהם כדי לתצוגה מקדימה על הכיסוי האמיתי.
- **אנימציית לחיצה, דהיית שחרור וספירת לחיצות.**
- **כיסוי לעכבר גם כן,** בחלון משלו: 200 עכברים תלת-ממדיים מציאותיים ב-13 משפחות, 100 ערכות צבעים, והצבע שבו הלחיצות שלך נדלקות. התאימו את הגוף, הרוחב, הגלגלת, משענת האגודל והכפתורים הצדדיים.
- **בנו פריסה משלכם** ב-Layout Designer: המקשים מקבלים את הגדלים האמיתיים שלהם. שנו שם, ערכו ומחקו פריסות ב-המקלדות שלי.
- **הציבו אותה בכל מקום:** גררו את המקלדת או את העכבר כדי להזיז, וגררו את הקצוות כדי לשנות גודל. קבעו את השקיפות ואם כל אחד מהם יישאר מעל החלונות האחרים.
- **הסתירו אותה לסיסמאות:** מקש קיצור אחד מסתיר את המקלדת ומפסיק לקרוא מקשים.
- **מקשי קיצור שעובדים בכל מקום:** Ctrl+F9 מזיז את המקלדת, Ctrl+Shift+F9 את העכבר, Ctrl+F10 מסתיר את המקלדת, Ctrl+F11 מציג או מסתיר את העכבר. אפשר לשנות את כולם.
- **72 פריסות שפה למקלדת** מודפסות על המקשים, והאפליקציה זמינה ב-**54 שפות**.

## הורדה

קבלו את הגרסה האחרונה מ[דף ההורדה](https://mynarecorder.com/input-visualizer/download) או מ[Releases](https://github.com/myna-recorder/Myna-Input-Visualizer/releases) בדף הזה: ה**מתקין** (הוא מתקין ב-Program Files ומבקש הרשאות מנהל פעם אחת), או קובץ ה**עצמאי** (standalone) שרץ בלי התקנה.

כשפותחים את הקובץ, Windows עשוי להציג "Windows הגן על המחשב שלך". בחרו **מידע נוסף**, ואז **הפעל בכל זאת**.

**דרישות:** Windows 10 (גרסה 2004 ומעלה) או Windows 11, 64 סיביות, וחיבור לאינטרנט בעת ההפעלה. היכנסו עם חשבון Myna, או המשיכו בלי חשבון.
