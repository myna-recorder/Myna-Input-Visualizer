화면을 있는 그대로 캡처하는 모든 화면 녹화 프로그램이나 스트리밍 도구, 즉 [Myna Screen Recorder](https://github.com/myna-recorder/Myna-Screen-Recorder), OBS, Streamlabs 또는 Windows Game Bar는 이 오버레이를 보이는 그대로 기록합니다. 그린 스크린도, 제목 표시줄도, 따로 지울 것도 없습니다.

## 기능

- **전체 키보드를 실시간으로.** 누를 때마다 키에 불이 들어옵니다. 평면, 3D 또는 3D 기울임으로 그릴 수 있습니다.
- **키 배열 12종:** 풀사이즈, 텐키리스, 60%, 65%, 75%, 96%, 40%, 게이밍, 숫자패드, 방향키, WASD 클러스터 또는 기능 키 줄.
- **키보드 케이스 500종, 색상 스타일 500종.** 떠 있는 키, 또는 키를 감싸는 케이스(슬림, 로우 프로파일, 우드, 레트로, 타자기, 러기드 등). 케이스에 포인터를 올리면 실제 오버레이에서 미리 볼 수 있습니다.
- **누름 애니메이션, 떼기 페이드, 누른 횟수.**
- **마우스 오버레이도 있습니다.** 별도의 창에서 사실적인 3D 마우스 200종(13개 계열), 색상 세트 100종, 클릭할 때 켜지는 색을 고를 수 있습니다. 본체, 너비, 휠, 엄지 받침, 측면 버튼을 맞춤 설정할 수 있습니다.
- **나만의 배열 만들기:** 레이아웃 디자이너에서 키는 실제 크기를 가집니다. '내 키보드'에서 이름을 바꾸고, 편집하고, 삭제할 수 있습니다.
- **원하는 곳에 두기:** 키보드나 마우스를 드래그해 옮기고, 가장자리를 드래그해 크기를 바꿉니다. 불투명도를 설정하고, 각각 항상 위에 표시할지 선택할 수 있습니다.
- **비밀번호 입력 시 숨기기:** 단축키 하나로 키보드를 숨기고 키 입력을 읽지 않습니다.
- **어디서나 작동하는 단축키:** Ctrl+F9는 키보드 이동, Ctrl+Shift+F9는 마우스 이동, Ctrl+F10은 키보드 숨기기, Ctrl+F11은 마우스 표시 또는 숨기기입니다. 모두 변경할 수 있습니다.
- **키보드 언어 72종**을 키에 표시하며, 앱은 **54개 언어**를 지원합니다.
