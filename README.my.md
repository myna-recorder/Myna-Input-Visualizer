## အင်္ဂါရပ်များ

- **သင့်ကီးဘုတ်တစ်ခုလုံး၊ တိုက်ရိုက်။** ကီးတစ်ခုစီကို နှိပ်သည်နှင့် မီးလင်းသည်။ ပြားချပ်ချပ်၊ 3D သို့မဟုတ် 3D tilted ပုံစံဖြင့် ဆွဲနိုင်သည်။
- **ကီးအပြင်အဆင် 12 မျိုး:** full size၊ tenkeyless၊ 60%၊ 65%၊ 75%၊ 96%၊ 40%၊ gaming၊ number pad၊ arrows၊ WASD cluster သို့မဟုတ် function row။
- **ကီးဘုတ်အမှု 500 နှင့် အရောင်ပုံစံ 500။** လွင့်နေသော ကီးများ သို့မဟုတ် ၎င်းကို ဝန်းရံထားသော အမှု: slim၊ low profile၊ wood၊ retro၊ typewriter၊ rugged နှင့် အခြားများ။ တစ်ခုပေါ်တွင် ကာဆာထားလိုက်ရုံဖြင့် အမှန်တကယ် overlay ပေါ်တွင် ကြိုတင်ကြည့်ရှုနိုင်သည်။
- **နှိပ်ခြင်းနှင့် လွှတ်ခြင်း အင်မေးရှင်း၊ နှိပ်ခဲ့သည့် အကြိမ်အရေအတွက်။**
- **မောက်စ် overlay လည်းရှိသည်၊ သီးခြား window ဖြင့်။** မျိုးစု 13 မျိုးမှ 3D မောက်စ် 200 ရှိပြီး အရောင်အစုံ 100၊ နှင့် သင့်ကလစ်များ လင်းသည့်အရောင်။ ကိုယ်ထည်၊ အနံ၊ ဘီး၊ လက်ထောက်နေရာနှင့် ဘေးဘက်ခလုတ်များကို ပြင်ဆင်နိုင်သည်။
- **Layout Designer ဖြင့် ကိုယ်ပိုင် layout ဖန်တီးပါ။** ကီးများသည် မူလအရွယ်အစားအတိုင်း ရှိသည်။ My keyboards တွင် အမည်ပြောင်းခြင်း၊ တည်းဖြတ်ခြင်းနှင့် ဖျက်ခြင်း ပြုလုပ်နိုင်သည်။
- **နေရာမရွေး ထားနိုင်သည်:** ကီးဘုတ် သို့မဟုတ် မောက်စ်ကို ဆွဲ၍ ရွှေ့ပါ၊ ဘေးထောင့်များကို ဆွဲ၍ အရွယ်ပြင်ပါ။ Opacity ကို သတ်မှတ်နိုင်သည်၊ နှင့် တစ်ခုစီကို အမြဲထိပ်တွင် ထားမထား ရွေးနိုင်သည်။
- **စကားဝှက်များအတွက် ဖျောက်ထားပါ:** hotkey တစ်ခုဖြင့် ကီးဘုတ်ကို ဖျောက်ပြီး ကီးများ ဖတ်ခြင်းကို ရပ်သည်။
- **နေရာတိုင်းတွင် အလုပ်လုပ်သော hotkeys:** Ctrl+F9 က ကီးဘုတ်ကို ရွှေ့၊ Ctrl+Shift+F9 က မောက်စ်ကို ရွှေ့၊ Ctrl+F10 က ကီးဘုတ်ကို ဖျောက်၊ Ctrl+F11 က မောက်စ်ကို ပြ သို့မဟုတ် ဖျောက်သည်။ အားလုံးကို ပြောင်းလဲနိုင်သည်။
- **ကီးပေါ်ရှိ ကီးဘုတ်ဘာသာစကား 72 မျိုး** နှင့် **ဘာသာစကား 54 မျိုးဖြင့် အက်ပ်**။
