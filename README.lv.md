## Funkcijas

- **Visa jūsu tastatūra tiešraidē.** Katrs taustiņš iedegas, kad to nospiežat. Zīmējiet to plakani, 3D skatā vai 3D sasvērtā skatā.
- **12 taustiņu izkārtojumi:** pilnā izmēra, bez ciparu bloka, 60%, 65%, 75%, 96%, 40%, spēļu, ciparu bloks, bultiņas, WASD klasteris vai funkciju rinda.
- **500 tastatūras korpusi un 500 krāsu stili.** Peldoši taustiņi vai korpuss ap tiem: plāns, zema profila, koka, retro, rakstāmmašīnas, izturīgs un citi. Novietojiet rādītāju virs kāda, lai to priekšskatītu īstajā pārklājumā.
- **Nospiešanas animācija, atlaišanas izbalēšana un nospiešanas skaitītāji.**
- **Arī peles pārklājums** savā logā: 200 reālistiskas 3D peles 13 saimēs, 100 krāsu komplekti un krāsa, kādā iedegas jūsu klikšķi. Pielāgojiet korpusu, platumu, ritenīti, īkšķa balstu un sānu pogas.
- **Veidojiet savu izkārtojumu** Izkārtojuma dizainerā: taustiņiem ir īstie izmēri. Pārdēvējiet, rediģējiet un dzēsiet tos sadaļā Manas tastatūras.
- **Novietojiet, kur vēlaties:** velciet tastatūru vai peli, lai to pārvietotu, velciet malas, lai mainītu izmēru. Iestatiet necaurredzamību un to, vai katrs paliek virs citiem logiem.
- **Paslēpiet paroļu ievadei:** viens taustiņš paslēpj tastatūru un pārtrauc taustiņu nolasīšanu.
- **Taustiņu kombinācijas, kas darbojas visur:** Ctrl+F9 pārvieto tastatūru, Ctrl+Shift+F9 pārvieto peli, Ctrl+F10 paslēpj tastatūru, Ctrl+F11 parāda vai paslēpj peli. Visas var mainīt.
- **72 tastatūras valodas**, drukātas uz taustiņiem, un lietotne **54 valodās**.

## Lejupielāde

Jaunāko versiju iegūstiet no [lejupielādes lapas](https://mynarecorder.com/input-visualizer/download) vai šīs lapas [Releases](https://github.com/myna-recorder/Myna-Input-Visualizer/releases) sadaļas: **instalētājs** (tas instalējas mapē Program Files un vienreiz prasa administratora tiesības) vai **patstāvīgais** exe fails, kas darbojas bez instalēšanas.

Atverot failu, Windows var parādīt ziņojumu "Windows protected your PC". Izvēlieties **More info** un pēc tam **Run anyway**.

**Prasības:** Windows 10 (2004. versija vai jaunāka) vai Windows 11, 64 bitu, un interneta savienojums palaišanas brīdī. Pierakstieties ar Myna kontu vai turpiniet bez konta.
