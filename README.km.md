## លក្ខណៈពិសេស

- **ក្តារចុចទាំងមូល បន្ទាន់។** ប៊ូតុងនីមួយៗបំភ្លឺនៅពេលអ្នកចុច។ គូសវាសមួយប្លង់ 2D ទិដ្ឋភាព 3D ឬ 3D ទ្រេត។
- **ប្លង់ក្តារចុច 12:** ពេញទំហំ, tenkeyless, 60%, 65%, 75%, 96%, 40%, ហ្គេម, ក្តារលេខ, ព្រួញ, ក្រុម WASD ឬជួរមុខងារ។
- **ករណីក្តារចុច 500 និងរចនាពណ៌ 500។** ប៊ូតុងអណ្តែត ឬករណីព័ទ្ធជុំវិញ៖ ស្តើង ទាប ឈើ បុរាណ ម៉ាស៊ីនវាយអក្សរ រឹងមាំ និងច្រើនទៀត។ ដាក់ទស្សន៍ទ្រនីមួយលើវា ដើម្បីមើលជាមុននៅលើគម្រប។
- **ចលនាចុច ការបាត់នៅពេលលែង និងចំនួនការចុច។**
- **គម្របកណ្តុរដែរ នៅក្នុងបង្អួចដាច់ដោយឡែក៖** កណ្តុរ 3D ពិតប្រាកដ 200 ក្នុងក្រុម 13, ឈុតពណ៌ 100, និងពណ៌ដែលការចុចរបស់អ្នកបំភ្លឺ។ កែតម្រូវតួ ទទឹង កង់ កន្លែងសម្រាកមេដៃ និងប៊ូតុងចំហៀង។
- **បង្កើតប្លង់ផ្ទាល់ខ្លួន** នៅក្នុង Layout Designer៖ ប៊ូតុងយកទំហំពិតរបស់វា។ ប្តូរឈ្មោះ កែ និងលុបនៅក្នុង My keyboards។
- **ដាក់នៅកន្លែងណាក៏បាន៖** អូសក្តារចុច ឬកណ្តុរដើម្បីផ្លាស់ទី អូសគែមដើម្បីប្តូរទំហំ។ កំណត់ភាពថ្លា និងថាតើនីមួយៗនៅលើគេជានិច្ច។
- **លាក់សម្រាប់ពាក្យសម្ងាត់៖** ផ្លូវកាត់តែមួយលាក់ក្តារចុច និងឈប់អានប៊ូតុង។
- **ផ្លូវកាត់ដែលដំណើរការគ្រប់ទីកន្លែង៖** Ctrl+F9 ផ្លាស់ទីក្តារចុច, Ctrl+Shift+F9 ផ្លាស់ទីកណ្តុរ, Ctrl+F10 លាក់ក្តារចុច, Ctrl+F11 បង្ហាញ ឬលាកកណ្តុរ។ អាចផ្លាស់ប្តូរទាំងអស់។
- **ភាសាក្តារចុច 72** បោះពុម្ពនៅលើប៊ូតុង ហើយកម្មវិធីមាន **54 ភាសា**។
