ნებისმიერი ეკრანის ჩამწერი ან სტრიმი, რომელიც ეკრანს იჭერს, მას ისე ჩაწერს, როგორც ის გამოიყურება: [Myna Screen Recorder](https://github.com/myna-recorder/Myna-Screen-Recorder), OBS, Streamlabs ან Windows Game Bar. მწვანე ეკრანი არ სჭირდება, სათაურის ზოლი არ არის, არაფრის ამოჭრა არ არის საჭირო.

## ფუნქციები

- **მთელი თქვენი კლავიატურა პირდაპირ ეთერში.** ყოველი ღილაკი ინათება, როცა დააჭერთ. დახაზეთ ბრტყლად, 3D-ში ან 3D დახრილად.
- **12 კლავიშების განლაგება:** სრული ზომა, tenkeyless, 60%, 65%, 75%, 96%, 40%, გეიმინგი, ციფრული ბლოკი, ისრები, WASD ჯგუფი ან ფუნქციონალური რიგი.
- **500 კლავიატურის კორპუსი და 500 ფერის სტილი.** ცურავი ღილაკები ან მათ გარშემო კორპუსი: თხელი, low profile, ხე, რეტრო, სამბეჭდი მანქანა, მტკიცე და სხვა. მიუთითეთ მაჩვენებელი ერთ-ერთზე, რომ ნამდვილ გადაფარვაზე გადახედოთ.
- **დაჭერის ანიმაცია, გაშვებისას გაქრობა და დაჭერების მრიცხველი.**
- **მაუსის გადაფარვაც,** საკუთარ ფანჯარაში: 200 რეალისტური 3D მაუსი 13 ოჯახში, 100 ფერის ნაკრები და ფერი, რომლითაც თქვენი დაწკაპუნებები ინათება. მოარგეთ კორპუსი, სიგანე, ბორბალი, ცერის საყრდენი და გვერდითი ღილაკები.
- **ააწყვეთ საკუთარი განლაგება** Layout Designer-ში: ღილაკები იღებენ თავიანთ რეალურ ზომებს. გადაასახელეთ, შეცვალეთ და წაშალეთ My keyboards-ში.
- **მოათავსეთ სადაც გნებავთ:** გადაათრიეთ კლავიატურა ან მაუსი მათ გადასატანად, გადაათრიეთ კიდეები ზომის შესაცვლელად. დააყენეთ გაუმჭვირვალობა და ის, რჩება თუ არა თითოეული ზედა ფენაზე.
- **დამალეთ პაროლებისთვის:** ერთი ცხელი კლავიში მალავს კლავიატურას და წყვეტს კლავიშების წაკითხვას.
- **ცხელი კლავიშები, რომლებიც ყველგან მუშაობს:** Ctrl+F9 გადაიტანს კლავიატურას, Ctrl+Shift+F9 მაუსს, Ctrl+F10 მალავს კლავიატურას, Ctrl+F11 აჩენს ან მალავს მაუსს. ყველა შეიძლება შეიცვალოს.
- **72 კლავიატურის ენა**, დაბეჭდილი ღილაკებზე, და აპლიკაცია **54 ენაზე**.

ფაილის გახსნისას Windows-მა შეიძლება აჩვენოს "Windows-მა თქვენი კომპიუტერი დაიცვა". აირჩიეთ **მეტი ინფორმაცია**, შემდეგ **მაინც გაშვება**.

**მოთხოვნები:** Windows 10 (ვერსია 2004 ან უფრო ახალი) ან Windows 11, 64-bit, და ინტერნეტ კავშირი გაშვებისას. შედით Myna ანგარიშით, ან გააგრძელეთ ანგარიშის გარეშე.
