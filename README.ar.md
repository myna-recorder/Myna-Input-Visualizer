## الميزات

- **لوحة مفاتيحك كاملةً، مباشرةً.** يضيء كل مفتاح عند ضغطه. ارسمها مسطّحة، أو ثلاثية الأبعاد، أو ثلاثية الأبعاد مائلة.
- **12 تخطيطاً للمفاتيح:** بالحجم الكامل، وبدون لوحة الأرقام، و60%، و65%، و75%، و96%، و40%، وتخطيط الألعاب، ولوحة الأرقام، والأسهم، ومجموعة WASD، أو صف مفاتيح الوظائف.
- **500 هيكل للوحة المفاتيح و500 نمط ألوان.** مفاتيح عائمة، أو هيكل يحيط بها: نحيف، ومنخفض الارتفاع، وخشبي، وريترو، وآلة كاتبة، ومتين، وغيرها. ضع المؤشر على أحدها لمعاينته على الطبقة الفعلية.
- **حركة الضغط، وتلاشي عند الإفلات، وعدّادات الضغط.**
- **طبقة للماوس أيضاً،** في نافذتها الخاصة: 200 ماوس ثلاثي الأبعاد واقعي في 13 عائلة، و100 مجموعة ألوان، ولون النقرات التي تضيئها. خصّص الهيكل والعرض والعجلة ومسند الإبهام والأزرار الجانبية.
- **ابنِ تخطيطك الخاص** في مصمم التخطيطات: تأخذ المفاتيح أحجامها الحقيقية. أعد التسمية والتحرير والحذف من «لوحات مفاتيحي».
- **ضعها أينما شئت:** اسحب لوحة المفاتيح أو الماوس لتحريكه، واسحب حوافه لتغيير حجمه. اضبط العتامة، وحدّد لكلٍّ منهما إن كان يبقى في المقدمة.
- **أخفها عند كتابة كلمات المرور:** مفتاح سريع واحد يخفي لوحة المفاتيح ويوقف قراءة المفاتيح.
- **مفاتيح سريعة تعمل في كل مكان:** Ctrl+F9 لتحريك لوحة المفاتيح، وCtrl+Shift+F9 لتحريك الماوس، وCtrl+F10 لإخفاء لوحة المفاتيح، وCtrl+F11 لإظهار الماوس أو إخفائه. يمكن تغيير كل منها.
- **72 لغة للوحة المفاتيح** مطبوعة على المفاتيح، والتطبيق بـ**54 لغة**.

## التنزيل

احصل على أحدث إصدار من [صفحة التنزيل](https://mynarecorder.com/ar/input-visualizer/download) أو من [الإصدارات](https://github.com/myna-recorder/Myna-Input-Visualizer/releases) في هذه الصفحة: **برنامج التثبيت** (يُثبَّت في Program Files ويطلب صلاحيات المسؤول مرة واحدة)، أو الملف **المستقل** التنفيذي الذي يعمل بلا تثبيت.

عند فتح الملف، قد يعرض Windows رسالة «حماية Windows لجهازك». اختر **معلومات إضافية**، ثم **تشغيل على أي حال**.

**المتطلبات:** Windows 10 (الإصدار 2004 أو أحدث) أو Windows 11، بنظام 64 بت، واتصال بالإنترنت عند بدء التشغيل. سجّل الدخول بحساب Myna، أو تابع بدون حساب.
