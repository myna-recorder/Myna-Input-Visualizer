<h1 align="center">Myna Input Visualizer</h1>

<p align="center">
  キーとクリックを、画面上に。<br>

[Myna Screen Recorder](https://github.com/myna-recorder/Myna-Screen-Recorder)、OBS、Streamlabs、Windows ゲーム バーなど、画面を録画・配信するツールは、画面に映っているとおりに記録します。グリーンバックも、タイトル バーも、抜き取り作業も不要です。

## 機能

- **キーボード全体をリアルタイムに。** キーを押すと、そのキーが点灯します。平面、3D、3D 傾斜のいずれでも描画できます。
- **12 種類のキー配列:** フルサイズ、テンキーレス、60%、65%、75%、96%、40%、ゲーミング、テンキー、矢印キー、WASD クラスター、ファンクション キー列から選べます。
- **キーボードケース 500 種、配色 500 種。** キーが浮いたデザインや、キーを囲むケース（スリム、ロー プロファイル、木製、レトロ、タイプライター、ラギッドなど）から選べます。ポインターを合わせると、実際のオーバーレイでプレビューできます。
- **押下アニメーション、離したときのフェード、押下回数の表示。**
- **マウス オーバーレイも用意。** 独立したウィンドウで表示され、13 のファミリーにわたるリアルな 3D マウス 200 種、配色セット 100 種、クリックの色を選べます。本体、幅、ホイール、親指レスト、サイドボタンをカスタマイズできます。
- **レイアウト デザイナーで自分だけのレイアウトを作成。** キーは実寸のサイズになります。マイキーボードで名前の変更、編集、削除ができます。
- **好きな場所に配置:** キーボードやマウスはドラッグで移動、端をドラッグしてサイズ変更できます。不透明度を設定でき、それぞれ常に手前に表示するかどうかも選べます。
- **パスワード入力時は非表示:** ホットキー 1 つでキーボードを隠し、キー入力の読み取りも停止します。
- **どこでも使えるホットキー:** Ctrl+F9 でキーボードを移動、Ctrl+Shift+F9 でマウスを移動、Ctrl+F10 でキーボードを非表示、Ctrl+F11 でマウスの表示/非表示を切り替えます。すべて変更できます。
- **キーに印字できる 72 のキーボード言語**、アプリは **54 言語** に対応。

## ダウンロード

最新版は[ダウンロードページ](https://mynarecorder.com/ja/input-visualizer/download)、またはこのページの [Releases](https://github.com/myna-recorder/Myna-Input-Visualizer/releases) から入手できます: **インストーラー**（Program Files にインストールされ、初回のみ管理者権限を求められます）、または、インストール不要で実行できる**スタンドアロン** exe。

ファイルを開くと、Windows に「Windows によって PC が保護されました」と表示されることがあります。**詳細情報** を選び、次に **実行** を選択してください。

**動作環境:** Windows 10（バージョン 2004 以降）または Windows 11、64 ビット。起動時にインターネット接続が必要です。Myna アカウントでサインインするか、アカウントなしで続行できます。
